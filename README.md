# prime-video-data-analysis-dashboard
Analyzed Prime Video content data using Python, Pandas, Plotly, and Dash to explore ratings, genres, and content trends through interactive visualizations.

For this project I have explored a Prime Video dataset using Python to better understand trends in content, genres, and IMDb ratings. The goal was to take a raw dataset, prepare it for analysis, and use visualizations to identify patterns that could provide insight into the types of content available on the platform. The project also includes an interactive dashboard that allows users to explore the dataset through filtering and dynamic visualizations.

I began by inspecting the dataset and identifying missing values, duplicate records, and inconsistencies that could affect the analysis. After cleaning and preparing the data, I performed exploratory data analysis (EDA) to better understand the distribution of ratings, the popularity of different genres, and relationships between key variables.

To visualize the data, I created charts that highlighted trends in IMDb ratings, genre distribution, and overall content characteristics. I then used Plotly and Dash to build an interactive dashboard where users can filter content by genre and explore the data in a more dynamic way.

The analysis showed that a large portion of the content is concentrated within a few major genres, while other genres are represented much less frequently. IMDb ratings were generally clustered within a moderate range, with fewer titles receiving extremely high or low ratings. The visualizations also helped reveal patterns in content distribution that were not immediately obvious from the raw dataset.

My Experience:
One of the most valuable parts of this project was learning how interactive dashboards can make data easier to explore and understand. Rather than relying on static charts, users can interact with the dashboard to focus on specific genres and compare trends across different groups of content.

One challenge was preparing the dataset for analysis by dealing with missing values and ensuring the data was formatted correctly for visualization. I also spent time learning how Dash callbacks work and how different dashboard components communicate with one another.

This project helped me become more comfortable moving through the full analytics workflow—from cleaning raw data, to exploring patterns, to presenting insights through an interactive dashboard. It also reinforced the importance of data preparation, as the quality of the analysis depends heavily on the quality of the underlying data.
